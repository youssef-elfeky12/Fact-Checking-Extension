## Model Details

**Mistral 7B Instruct v0.2**

- Parameters: 7 billion
- Quantization: 4-bit (NF4 format via bitsandbytes)
- Size: ~3.5-4GB on disk/memory
- Context: 8192 tokens (uses ~150 tokens per explanation)
- Speed: ~1-2 seconds per explanation on GPU

## Explanation Quality

### Without LLM (Template-based)

```
This claim appears likely true based on 3 evidence source(s).

```

```
The claim is likely true. Scientific evidence confirms that water boils

```

The LLM provides:

- More natural phrasing
- Better context integration
- Concise summarization
- Citation of key evidence points

## Troubleshooting

### bitsandbytes Installation Issues (Windows)

bitsandbytes can be tricky on Windows. If you get errors:

1. **Pre-built wheels**: Try installing a pre-compiled version

   ```cmd
   pip install bitsandbytes-windows
   ```

2. **Alternative**: Use CPU-only mode (slower)

   - The code auto-detects and falls back to CPU if CUDA unavailable
   - Model loads without quantization (~14GB - may not fit!)

3. **Skip Step 4**: If bitsandbytes won't install, just don't set `ENABLE_LLM_EXPLAINER=true`
   - API works fine with template explanations
   - You can always add it later

### Out of Memory

If you get CUDA out of memory errors:

- Close other GPU applications
- Reduce `max_length` in `explainer.generate_explanation()` (default: 150)
- Consider using a smaller model (e.g., Mistral 7B Instruct v0.1)

### Model Download Fails

- Check internet connection
- Verify access to https://huggingface.co/
- Model cached at: `C:\Users\youss\.cache\huggingface\hub\`
- Can manually download and place in cache
